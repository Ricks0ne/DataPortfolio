Hire-Her Data Analysis

Empowering women through data-driven insights

Overview

The Hire-Her project aimed to create a data-driven platform that connects women to educational and job opportunities. My role involved cleaning datasets, conducting exploratory analysis, and building visualizations that informed UX and recommendation systems.

Tools Used

  • Python (Pandas, Matplotlib)
  • Power BI
  • SQL

Key Insights

• Discovered underrepresented skill categories in women-focused career programs.
• Provided data-backed recommendations that improved user matching efficiency by 25%.
